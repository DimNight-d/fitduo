# FitDuo

Локальна програма схуднення (для однієї людини або для пари): розрахунок калорій, меню з простих продуктів, калькулятор страв із попередженнями, запланований алкоголь, список покупок, тренування вдома на 12 тижнів, журнал ваги й замірів, фото прогресу.

## Як запустити
Двічі клацніть `index.html` — відкриється в Safari. Інтернет не потрібен.
Зручно: перетягніть `index.html` на панель «Вибране» в Safari.

## На двох Mac
Скопіюйте всю папку на інший Mac і відкрийте `index.html` у Safari. На першому екрані виберіть «Тільки для мене».
Дані кожного Mac окремі й не синхронізуються.

## Важливо про дані
- Усе зберігається в Safari на цьому Mac (окремо для цього файлу).
- Не переносьте й не перейменовуйте папку — Safari вважатиме це іншою програмою.
- Раз на 1–2 тижні: «Профілі» → «Зберегти резервну копію» (файл з'явиться в «Завантаженнях»).
- Очищення історії/даних сайтів у Safari видалить і дані програми — спершу зробіть копію.

## iPhone (вебзастосунок)
Адреса: **https://dimnight-d.github.io/fitduo/** (GitHub Pages, репозиторій `DimNight-d/fitduo`).
На iPhone: відкрити адресу в Safari → «Поділитися» → «На початковий екран». Відкривати лише з іконки.
Дані кожного телефона окремі й нікуди не надсилаються: у репозиторії лише код.

## Після змін у коді
1. `tools/bump-version.sh <номер>` — оновлює `?v=` в `index.html` і версію кешу в `sw.js`.
2. `git commit -am "…" && git push` — GitHub Pages оновить сайт за 1–2 хвилини.
iPhone підтягне нову версію при наступному відкритті з інтернетом.

## Структура
- `js/foods.js` — продукти й страви меню, `js/dishes.js` — готові страви для калькулятора, `js/foodcalc.js` — калькулятор і заміни, `js/exercises.js` — вправи, `js/figures.js` — анімовані фігурки
- `js/calc.js` — розрахунки (Міффлін–Сан Жеор, дефіцит, БЖВ, корекція кожні 2 тижні)
- `js/plan.js` — генерація меню, порцій, покупок і тренувань
- `js/app.js`, `js/onboarding.js`, `js/player.js` — екрани, анкета, плеєр тренувань
